# Documentation

These guides help you get from choosing a skill to using it with confidence. Start with the [catalog](../README.md#available-skills) to find and download a skill; its own page explains what it does. The guides below work with any skill in the collection.

Pick the question that sounds most like yours:

| Guide | Where it helps |
| --- | --- |
| [Install a skill](installation.md) | You have the ZIP and want to put it where your agent finds it, upload it to an AI chat app, upgrade it, or share one copy between agents. |
| [Build a skill from source](building-from-source.md) | The skill has no release yet, you want changes newer than the latest release, or you're building your own modified copy. |
| [Get good results](using-skills.md) | The skill is installed and you're wondering how to phrase the request or which model setting to use. |
| [When a skill is skipped or the result looks wrong](troubleshooting.md) | Your agent can't see the skill, ignored it, or produced something surprising. |
| [What the skills are designed to do](design-principles.md) | You want to know what these skills aim for, and where their promises end, before trusting one with real work. |
| [Questions, reports, and defects](feedback.md) | You have a question, a story from a real task, or a defect to report. |
