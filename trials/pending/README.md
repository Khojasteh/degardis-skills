# Pending Questions

A trial sometimes raises a useful question that it cannot settle in the same run: whether a rule holds in a case no fixture covers, for example, or whether an observed behavior came from the skill or the agent running it. Those questions wait here, one directory per skill, so a later trial can pick them up with the context it needs.

Each `<skill-name>/README.md` is that skill's queue, grouped by state. Anything a future run of a question needs, such as an exact prompt or a sanitized input, sits beside the queue in the same directory.

Once a question is settled, it is removed rather than marked closed. A skill whose queue is empty has no directory here. This keeps the page focused on what still needs an answer; if a question is not listed, no trial is currently waiting on it.
